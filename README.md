# Hi, I'm Antony 👋

I've been developing software with **Delphi for over 30 years**, and I'm still very much enjoying building things with it.

These days I'm working with **Delphi 13**, using **Kai and AI-assisted development** to explore just how far Delphi can be pushed when modern AI tooling is combined with decades of Delphi experience.

## 🔨 What I'm working on

A big part of my current work is creating **new component sets and developer tools for Delphi**.

My aim is to:

- Build modern, high-quality **Delphi component libraries**
- Produce **more complete component sets**, following on from my DaisyUI work
- Create genuinely useful **developer applications and tools**
- Explore how AI-assisted development can help bring ambitious Delphi projects to life
- Release as much useful work as I can for other Delphi developers

And I've got plenty more ideas waiting to be built. 😊
